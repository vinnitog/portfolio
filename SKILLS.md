## Skills Ativas

- `brainstorm-ideas-new`
- `brainstorm-ideas-existing`
- `business-model`
- `monetization-strategy`
- `pricing-strategy`
- `impeccable`

Somente as skills listadas acima estao instaladas localmente. Se o escopo mudar, gere novamente com `-SkillSet All` ou instale a skill ausente antes de exigi-la no workflow.

As mesmas skills sao mantidas em dois caminhos para descoberta nativa:

- Codex e agentes compativeis: `.agents/skills/`
- Claude Code: `.claude/skills/`

## Quando Usar

- Ideacao: `brainstorm-ideas-new` para produto novo e `brainstorm-ideas-existing` para evoluir produto existente.
- Modelo de negocio: `business-model` antes de assumir como o produto cria, entrega e captura valor.
- Monetizacao e preco: `monetization-strategy` para explorar modelos de receita; `pricing-strategy` para definir faixas, metricas e experimentos de preco.
- Front-end: `impeccable` em qualquer trabalho de design, redesign, auditoria ou refinamento visual.
- Dados pessoais: `lgpd-audit` como orquestrador; use uma `lgpd-*` especifica quando o pedido tiver escopo pontual.
